## 修复

- **备份导入崩溃（P1）**：深层嵌套/畸形 JSON 在交给递归解析器前被拒绝，异常转为“备份格式或版本不支持”；App 不再因 `StackOverflowError` 退出，数据库保持不变。
- **撤销窗口（P2）**：撤销条改用带身份的自定义 Snackbar 语义，5 秒从该条真正显示时开始计时；连续完成时最新一次撤销完整保留约 5 秒，不再误关其他提示或无限停留。
- **浅色系统栏（P2）**：编辑页移除无条件白色系统栏设置，状态栏/导航栏图标跟随实际主题；浅色下时间、电量与手势清晰可读。
- **大字号主题选择（P2）**：设置页主题选项改为 `FlowRow`；200% 字号下“跟随系统 / 浅色 / 深色”全部可见、可点击、可朗读。
- **更新包状态（P3）**：已下载安装包记录对应版本；检查到新版本时丢弃过期包；检查失败时已校验安装包仍可安装。
- **重新下载（P3）**：下载写入临时文件，校验通过后原子替换；取消或失败保留原安装包，并提供“安装已下载版本”。
- **清单名校验（P3）**：拒绝换行、行分隔符和控制字符；导入非法清单名时返回具体原因。
