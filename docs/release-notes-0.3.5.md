# 忘了没 v0.3.5 · 闭环状态与桌面刷新

2026-11-10。本版不增加新功能模块，只把现有闭环的状态反馈、桌面刷新和编辑页键盘行为做对。

## 改进

- **全部完成不再说成“清单空空”**：小部件和主页面现在区分“从未记录”与“已有记录且全部完成”。待办显示“都完成了”，待买显示“都买齐了”；小部件空态提供“再记一条”入口。
- **待买文案独立**：主页面使用“N 样东西，等你买”“都买齐了，心里轻轻”“还没要买的”，筛选计数使用“N 件待买 / N 件已买”，不再与待办混用“小事 / 完成”。
- **已完成筛选计数修正**：切到“已完成 / 已购买”时，计数显示当前筛选的记录数，不再一直显示未完成数。
- **编辑已有记录不自动弹键盘**：从桌面点击一条被截断的记录时，先展示完整标题和备注；用户点输入框后再弹出键盘。新增记录和“保存并继续”仍自动聚焦并弹出键盘。
- **桌面刷新更可靠**：新增开机和覆盖安装广播接收器，启动后刷新全部小部件；回到 App 时也补一次刷新。仍保留数据变更后的即时刷新。
- **小部件选择器预览**：标准和大小部件分别使用带示例记录、数量和新增入口的静态预览布局，并为旧桌面补充 `previewImage`，不再显示空卡片。
