## 移除待买类型与数据迁移（v1→v2）

- 只保留待办一种清单类型，移除「待买」及数量/单位字段，应用简化为单一清单体系。
- 数据库自动迁移（v1→v2），覆盖安装升级无需手工操作：
  - 待买清单（含默认「日常采购」）删除，其中全部记录按创建先后**追加到「随手待办」末尾**。
  - 数量/单位按既有跨类型规则清除，标题、备注、置顶、完成状态全部保留。
  - 绑定待买清单的桌面小部件自动改绑「随手待办」，撤销入口清除；上次所选清单保留。
- 备份兼容：v0.3.x 导出的备份仍可导入（旧待买清单并入随手待办并丢弃数量/单位）；新版导出的备份兼容旧版导入。
