# 产品规格 v1.0

实施更新：用户已确认目标系统为 **澎湃 OS 3**。本文仍为完整 MVP 目标；当前原生基础框架的实现范围与未完成项以 [框架状态](07-framework-status.md) 为准。普通桌面与负一屏验收分开；已确认负一屏不接受标准 Android Widget，且小米小部件要求应用商店上架/审核，该项目采用自有 APK 下发，故负一屏不作为目标。

## 1. 目标与范围

用户：主要使用小米手机的个人用户，临时记录要做的事和要买的东西。核心闭环：桌面看到 → 一步进入录入 → 保存回桌面 → 原地勾选。

MVP 必须包括：两类清单、记录 CRUD、置顶、数量单位、批量添加、搜索、完成与恢复、多实例 Widget、实例配置、草稿、手动备份恢复、浅深色主题、无障碍。

不包括：时间提醒、重复任务、截止时间、登录、云同步、家庭共享、AI 分类、图片、录音、广告、自动剪贴板读取、小米小部件中心上架、悬浮窗。不要为未实现功能展示可点击入口。

平台基线：Android 8.0/API 26 起可安装；重点验收小米系统桌面 + Android 12～16。具体型号、HyperOS/MIUI/桌面版本需在真机验收记录中填写，尚未提供的设备不算已通过。Android 17 若为目标真机系统，加入矩阵，不以此阻塞基础开发。

## 2. 信息架构与页面 ID

| ID | 页面 | 入口 / 返回 |
|---|---|---|
| W01 | 标准 Widget | 桌面添加；正文到 E01，新增到 E01，标题到 A01 |
| W02 | 大 Widget | 与 W01 共用行为，显示更多行 |
| E01 | 快速新增/编辑 | 独立 Activity；Widget 进入保存后 finish 回原宿主；App 进入回清单 |
| A01 | 清单主页面 | 默认上次类型/清单；底部待办、待买、设置 |
| A02 | 已完成列表 | A01 状态切换；可恢复/编辑/删除 |
| A03 | 清单管理 | 清单标题旁管理；新建、重命名、删除 |
| S01 | 设置 | 主题、添加小部件指导、备份导入导出 |
| C01 | Widget 配置 | 初次添加或系统重新配置；选择一个明确清单、主题和密度 |

默认清单：`list-todo-default` / 随手待办 / TODO；`list-shopping-default` / 日常采购 / SHOPPING。默认清单不可删除，可重命名。类型创建后不可修改。记录类型由所属清单推导，不额外存一份类型字段。

## 3. A01 主页面

顶部：品牌、当前清单选择、未完成数；中部搜索框、未完成/已完成分段切换、记录列表；底部固定主导航和“记一条”。

- 类型切换恢复各自上次清单，无有效值时选择对应默认清单。首次默认待办。
- 搜索只作用当前清单、当前状态；匹配标题与备注的字面子串，忽略英文大小写；`%` 和 `_` 视为文字，不作为 SQL 通配符。
- 切换清单/类型清空搜索并回到未完成。完成/恢复操作不改变所选清单。
- 未完成排序：置顶优先；同组 sortKey 升序、createdAt 升序、id 字典序升序。
- 已完成排序：completedAt 降序、id 升序。不显示在 Widget 正常记录区。
- 新记录 sortKey = 当前清单最大 sortKey + 1024；首条为 1024。恢复保留原排序位置。
- 正文点击编辑；勾选区域只执行状态命令，不冒泡打开编辑器。置顶只在编辑器设置。
- 删除只在编辑器中提供，确认后软删除。第一版无回收站入口；完整备份不导出软删除项。
- 完成或恢复使用 5 秒 Snackbar 撤销（进程内；页面结束后不保留），撤销采用版本检查。

## 4. E01 快速编辑

打开时标题输入框获取焦点，Activity 获得窗口焦点后请求 IME；若输入法未弹出仍保留可点击输入框。使用正常安全窗口处理，不申请悬浮窗或后台弹窗权限。

字段：标题、目标清单、备注、置顶；待买额外显示数量和单位；新增时有“每行生成一条”开关。类型切换通过目标清单选择实现，跨类型移动到待办时明确提示将清除数量和单位，确认才提交。编辑时不提供批量模式。

| 字段 | 规则 |
|---|---|
| 标题 | trim 后 1～200 Unicode 码点；单条不允许换行；空值报“先写点要记的内容” |
| 备注 | 可空，最多 2000 Unicode 码点，保留内部换行 |
| 清单名 | trim 后 1～20 码点；同类型内忽略大小写不重名；报“这个名字已经用过了” |
| 数量 | 可空；十进制正数 0.01～9999.99，最多两位小数；不允许科学计数法、负数、NaN |
| 单位 | 可空，trim 后最多 12 码点；填写单位必须填写数量 |
| 批量 | 按 CRLF/LF 拆分，trim、忽略空行，1～50 条；每条独立通过标题校验 |

批量模式数量/单位隐藏且不提交，备注/置顶应用于每一条，整批在同一事务中保存，任意一行失败则全部不保存；不自动去重。显式写“将生成 N 条”，错误指出原始行号。

保存：点击后禁用提交按钮，数据库提交成功后再退出。失败保留内容、恢复按钮并提示“没有保存成功，请重试”。键盘 Done 等同“保存”；批量 textarea 的 Enter 仅换行，使用按钮提交。“保存并继续”仅新增时提供，成功后保留清单及批量开关，清空其他字段并重新聚焦标题。

草稿：字段变化 debounce 300ms 写 Room；onStop 尽力补写，不能承诺突然断电前的最后 300ms。草稿 key = `create:{listId}` 或 `edit:{itemId}`，同时保存编辑时 baseVersion。Back 优先收起 IME；再次 Back 保留草稿并退出，点击显式“取消”也保留草稿。下次同入口恢复并显示“已恢复上次草稿 · 丢弃”；保存成功才删除草稿。编辑对象已删除或版本不同，提示冲突，不自动覆盖。

## 5. Widget 交互与配置

两种 Provider，标准建议 4×2、大号建议 4×4；实际使用宿主尺寸和密度计算，格数不能当作物理尺寸承诺。标准布局通常 3 行，大号通常 7 行；字体放大后减少行数，至少保留标题、1 行记录和新增入口。初版使用固定数量可见行，不实现滚动列表、手势切换、桌面拖动排序。

结构：标题/未完成总数 → 记录区 → “＋记一条 / 全部”。超长标题单行省略，点击可看全文；数量在右侧留有限宽，标题获得剩余宽度。每个实例只绑定一个清单，可跨两个类型选择。

- 圆圈：`SetCompleted(itemId, true, expectedVersion)`，成功后替补下一行。
- 正文：直接 PendingIntent.getActivity 打开 E01(itemId, originWidgetId)。
- 新增：直接打开 E01(listId, originWidgetId)。
- 标题/全部：直接打开 A01(listId)，显示未完成。
- 完成后该 Widget 页脚改为“已完成 · 撤销”，并保留“＋”入口。撤销入口持续到该实例下一次成功完成操作替换它、任何已成功撤销、相关记录被修改/删除，或实例配置发生变化。没有精确计时消失，不依赖后台倒计时。仅该实例显示该入口，其他绑定同清单实例正常刷新。
- 撤销仅在 item 当前 version 与完成后的版本相符时允许；冲突后清除入口并提示“记录已变化，请到 App 查看”。Widget 本身错误可在页脚显示，下次正常刷新恢复。
- 无记录：显示“还没有待办/待买”与新增入口。数据读取失败显示“暂时无法读取 · 点此重试”，不得以空列表伪装失败。
- 首次配置取消：不创建可用 Widget，遵守 RESULT_CANCELED；保存配置后立即生成首帧，再 RESULT_OK。
- 每个实例配置：listId、theme(SYSTEM/LIGHT/DARK)、density(COMFORTABLE/COMPACT)。Provider 决定标准/大版，不存重复 size 字段。
- 绑定清单被删除：同一事务迁移记录到同类默认清单、重绑受影响 Widget、清除其撤销记录，再刷新。

## 6. 清单管理与备份

新建清单默认使用当前类型；重命名不改变 ID。删除非默认清单前提示“其中 N 条记录将移到『默认清单名』，关联小部件也会切换”，确认后执行。默认清单删除按钮禁用并说明原因。

导出：系统文件选择器，建议名 `wanglemai-backup-YYYYMMDD-HHmm.json`。导出未软删除的清单和记录，包括已完成项；不含草稿、Widget ID、撤销命令和设备设置。

导入：选择文件 → 校验 → 显示清单/记录数量 → 确认合并。schemaVersion=1；未知版本/格式错误/超额/非法引用全部拒绝，数据库不变。最多 5MB、100 个清单、10000 条记录。按 ID 合并：已有 ID 保留本机，新增项导入；同 ID 不同类型的清单为冲突，整批拒绝；名称冲突为新清单附加“（导入2）”等并保证总长 20。不存在的默认清单先建立。操作事务化，成功后所有 Widget 刷新。结果报告新增、跳过数量。不要悄悄覆盖本机数据。

## 7. 视觉、触达与文案

方向：温暖米白背景、墨绿主操作、柔和橙色待买标签；大面积留白，避免效率工具变成信息仪表盘。字体跟随系统，标题 22sp/medium、正文 16sp、辅助 12～14sp；点击目标至少 48dp。主体边距 20dp、卡片内边距16dp、行高最小52dp、卡片圆角24dp（Widget 服从宿主裁剪及系统圆角）。

颜色基线：浅色 background #F5F4EE、surface #FFFFFF、text #202D28、secondary #65736B、primary #215B45、onPrimary #FFFFFF；深色 background #141B17、surface #202B24、text #E7EEE8、secondary #B2C0B7、primary #A5D7B9、onPrimary #123523；错误色浅 #A32929 / 深 #FFB4AB。以可读性测试为准，不硬编码文字像素。

TalkBack：勾选播报“标记『牛奶』为已购买”；正文和勾选各自独立焦点；数量与标题关联播报；错误为 live region；颜色不单独表达完成状态。大字体不遮挡新增和保存。

## 8. 原型覆盖与边界

prototype/index.html 是可离线操作的浏览器参考原型：两个实例同步数据、编辑、批量、搜索、清单管理、配置、主题、撤销、备份。演示工具条属于评审工具，不进入 Android 产品。

简化：浏览器存储代替 Room；浏览器输入法代替 Android IME；编辑面板在手机预览容器内绘制，不是原生 Activity；浏览器即时重绘代替 AppWidgetManager；草稿在浏览器输入事件同步存储；UI 演示样例不是正式应用默认用户数据。浏览器原型不证明 APK 构建、Android生命周期、系统桌面刷新、进程恢复、小米兼容或无障碍通过。
